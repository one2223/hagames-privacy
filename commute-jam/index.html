Support

Restore “No Ads” on a new device

Open Settings in the game and tap Restore Purchases, signed in with the same Apple ID.

I bought something but did not get it

Make sure you are online and restart the game — a purchase that did not finish is delivered on the next launch. If it still does not arrive, email us with the order ID from Apple’s receipt email.
